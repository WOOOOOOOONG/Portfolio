  • PK를 (user_id, viewed_at, history_id) 복합 키로 변경
  • 6억 건 무중단 마이그레이션 — 이중 쓰기 + 배치 백필(chunk 100만) + 트래픽 1%→100% 컷오버 자체 설계·구현
  • Heavy User 최근 50건은 Redis LPUSH+LTRIM 50으로 보조 캐싱
  • 이후 동일 패턴 대규모 DDL 작업 자동화를 위해 gh-ost 도입
